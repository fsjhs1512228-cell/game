📖 專案簡介 (Introduction)
「文言文解密特訓營」 是一款結合遊戲化機制（Gamification）與國風青綠山水美學的一頁式互動學習平台。
許多國中生在面對文言文時，常因「語序倒裝」、「主詞省略」以及「詞性混亂」而感到挫折。本專案將枯燥的課本練習轉化為打怪升級的特訓營，以**四大核心詞性（名詞/主語、代名詞、形容詞、副詞）**作為解密密碼，引導學習者輕鬆看懂《長歌行》、《過故人莊》以及超過 30 首精選唐詩、宋詞、元曲！
此外，本專案亦整合了由 Suno AI 創作的幽靜純音樂主題曲**《山居聽泉》**（結合古箏、古琴、竹笛與深山夜雨聲），提供無干擾的沉浸式讀書氛圍。

💡 專案緣由與動機 (Motivation & Origin)

🎯 痛點剖析
文言文看懂字卻不懂句：國中生常能認出單字，但因為不熟悉「主詞省略」與「語序調整」，無法快速理解全句含意。
傳統刷題枯燥乏味：傳統參考書題目單調，缺乏即時反饋與成就感，容易產生學習排斥感。
缺少專注的學習氛圍：閱讀古典詩詞需要靜心，但市面上缺乏專為文言文閱讀設計的沉浸式古典背景音效。
🚀 創作動機
希望建立一個免費、免安裝、一鍵開啟的單一網頁應用程式（Single-File Web App），讓學生能在遊戲化的關卡、XP 經驗值與古典樂章的陪伴下，反覆練習並建立對文言文的直覺與自信。

🌟 專案核心特色 (Key Features)

1. 🔑 四大詞性極速拆解秘笈
專為國中語文課綱設計的零失敗分辨口訣：
名詞（主詞/主角）：標記句中「誰在做動作」（如：葵、樹、山）。
代名詞：精準還原「吾、汝、其、之」等指代對象。
形容詞：修飾名詞的狀態與顏色（如：「青青」園中葵、「綠」樹）。
副詞：辨識修飾動詞的程度與轉折（如：老大「徒」傷悲、「甚」異之）。

2. 🟢 🟡 🔴 三級難度分級試煉
初級（易）：單音節擴詞、基礎形容詞與高頻虛詞（之、乎、者、也）。
進階（中難）：針對國中課本重點《長歌行》、《過故人莊》，專攻「主詞省略」還原。
挑戰（難）：包含《史記》、《世說新語》等經典短篇，挑戰倒裝句型與綜合句意剖析。

3. 📜 唐詩 ‧ 🎵 宋詞 ‧ 🪕 元曲 龐大寶庫 (30+ 名篇)
每類別均收錄 10 首以上國中必考與經典名篇（如《水調歌頭》、《天淨沙·秋思》、《山坡羊·潼關懷古》）。
提供完整原文、逐句白話譯文、意境賞析與高亮互動語法點撥。

4. 🔍 詩詞自選與 AI 動態拆解
支援輸入任意詩詞名稱或詩句，系統將自動進行分句、詞性高亮，並動態產生互動選擇題與 XP 獎勵。

5. 🎶 主題曲《山居聽泉》Suno AI 指令集
內建專為閱讀文言文設計的 Suno AI Prompt 複製面板。
採用 Web Audio API 打造擬真古箏/古琴五音音階合成器，點擊即可線上試聽悠揚旋律。

🎓 預期學習收穫 (Learning Outcomes)
🧑‍🎓 對於學習者（學生）：
